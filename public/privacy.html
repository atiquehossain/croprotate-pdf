Privacy notice

Private by design

CropRotate PDF edits documents locally in your browser. Your PDFs and any passwords you enter are processed only in the active browser tab. The app does not upload them or keep a server-side copy.

Your document stays under your control. Edits are temporary until you download the result. Closing or reloading the tab discards the working session. You keep ownership of your files and outputs.

What stays in the tab

Selected PDF bytes, generated previews, passwords, crop and rotation choices, page order, selections, and undo history live in browser memory for the active editing session. Merging, splitting, duplication, reordering, removal, and extraction also happen in that tab. CropRotate PDF does not use cookies, local storage, session storage, IndexedDB, analytics, or a server database to retain those document contents.

When data leaves the tab

  • A new PDF download is requested only when you explicitly choose Save local copy or Extract selected.
  • The original file is not modified by the app.
  • Reloading, closing the tab, or opening another PDF ends the current working session.

Cropping is not redaction

Cropping changes which part of a PDF page is visible. It does not reliably erase content outside the crop. Use a dedicated redaction tool when hidden content must be permanently removed.

Editing is not sanitizing

CropRotate PDF is not a malware scanner or PDF sanitizer. Active content, actions, attachments, and other data from an original PDF may remain in an exported file. Open only documents you trust and continue treating outputs as untrusted when their source was untrusted.

Hosting and ordinary connection data

The static app is hosted on GitHub Pages. Like other web hosts, GitHub may receive ordinary connection information such as an IP address, request time, requested page, browser details, and referring page. Your browser may cache the app's code and visual assets for performance and offline use. The offline cache uses an explicit list of app files; it does not cache selected PDFs, passwords, previews, edits, generated downloads, or arbitrary requests. None of these app-cache operations sends the PDFs you selected to the app's host.

Things outside this app

Browser extensions, operating-system memory or swap behavior, download history, cloud-synced download folders, and any software that opens the exported file are controlled by your browser, device, or third-party services—not by CropRotate PDF. Use a browser and device you trust when working with sensitive documents.

Your files remain yours

You keep control and ownership of documents you open and outputs you create. CropRotate PDF does not claim ownership of them.
